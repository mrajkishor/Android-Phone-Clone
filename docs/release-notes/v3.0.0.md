## 📱 Android Phone Clone v3.0.0 — *Unstoppable*

Move everything from your old Android phone to your new one over Wi-Fi, checksum-verified and without duplicates. v3 makes long transfers survive timeouts, Wi-Fi drops, pauses and the app being closed.

### ⬇️ Install
1. Download **`PhoneTransfer-v3.0.0.apk`** below.
2. Install it on **both** phones (Android 7.0+). Both phones must run v3.
3. New phone → *This is the NEW phone*. Old phone → *This is the OLD phone* → scan the QR code.

### ✨ What's new in v3
- **Live per-file progress:** the name, folder and bytes in flight, updated about 10 times a second.
- **Stall timeout + retry queue (DLQ):** a file stuck for 20 s is skipped and retried after the others with exponential backoff (5 → 10 → 20 → 40 s), up to 5 attempts.
- **🎉 or a clear failed list:** each file that couldn't be sent, with its full path and error, plus **Copy list** and **Try again** buttons.
- **Pause / Resume** from the exact byte.
- **Byte-level resume** after pauses, retries, reconnects and app restarts.
- **Automatic reconnect** when Wi-Fi drops.
- **Background running:** a foreground service with a progress notification. Keeps going if you swipe the app away.
- **Index-based duplicate skipping** on every restart.

### ✅ Still included from v1 and v2
Automatic detection of every file · same folders and original dates · SHA-256 verification · no duplicates · contacts with full photos (existing ones skipped) · QR pairing · the old phone is never changed.

### 🧪 Quality
6 end-to-end tests run the real sender against the real receiver: exact copies, no duplicates, stop and resume, stall → retry queue → recovered, permanent failure → final list, and pause → resume at the same byte.

### ⚠️ Notes
- Allow notifications so you can see background progress.
- On Xiaomi, Oppo, Vivo, Realme or Samsung phones, set the app's battery usage to **Unrestricted** on both phones.
- Not transferable by any regular app: installed apps and their data, SMS, call logs, and in-app chat histories.
