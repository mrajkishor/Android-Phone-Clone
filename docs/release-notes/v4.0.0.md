## ⚡ Android Phone Clone v4.0.0 — *Fast*

Everything from v3 (verified, no duplicates, pause/resume, retry queue, background running), now **several times faster**, and you can **update to it in the middle of a transfer**.

### ⬇️ Install
1. Download **`PhoneTransfer-v4.0.0.apk`** below and install it on **both** phones (Android 7.0+).
2. **Coming from v3?** It installs over v3 as an update and keeps your progress. Pause, update both phones, scan the QR code once, and continue. Finished files are skipped and half-sent files resume from the same byte.

### ✨ What's new
- **2–6 files in flight at once**, adjusted automatically to your Wi-Fi, with a dedicated lane for large files.
- **Small files in batches** of up to 300 per request, each still SHA-256 verified.
- **Identical files sent once** and copied on the new phone.
- **Checksums in background threads** and **batched media indexing**.
- **One-tap "Continue previous transfer"**, with no QR scan after a restart or update.
- **Works with v3 phones** in either direction (one file at a time until both are on v4).
- Every file and batch in flight is shown live on both phones.

**Typical gain:** 3–8× faster than v3 for phones full of photos, and 10×+ for lots of tiny documents. For the fastest setup, use the new phone's 5 GHz hotspot with the phones side by side.

### 🧪 Quality
10 end-to-end tests: everything from v3, plus parallel lanes, batches and cloning; update from v3 with a half-sent file; QR compatibility; and a v3 new phone.

### ⚠️ Notes
- Allow notifications so you can see background progress. On Xiaomi, Oppo, Vivo, Realme or Samsung phones, set battery usage to **Unrestricted** on both phones.
- Not transferable by any regular app: installed apps and their data, SMS, call logs, and in-app chat histories.
